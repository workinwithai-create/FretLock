# FretLock

Fretless bass groove desk for music makers struggling to lock a pocket.

Live CC0 fretless bass samples. Set your BPM (60–180) and chord progression. Plays a tight groove on the audio clock. Live changes apply next step. Exports WAV + MIDI on the DAW grid (48 kHz, 24-bit, downbeat at sample 0, seamless loop).

Distinct from BassForge (electric focus) and other WorkinWithAI desks.

## Pricing recommendation
One-time $29 (or $9/mo subscription for updates and extra recipes). Best place to sell: Gumroad or Lemon Squeezy (simple license key check). README says free for this MVP demo; add gate for paid.

## Demo
Short demo video: play 8 bars at 92 BPM, change chords live, export, import to DAW and loop.

## Acceptance
Follows WorkinWithAI Audio Engine rules 1–4, 5–9. Samples bundled under /public/samples/. No @main. No random in export.
